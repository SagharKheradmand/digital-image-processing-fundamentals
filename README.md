
# Digital Image Processing Fundamentals

## Overview

This project presents several fundamental Digital Image Processing techniques implemented as part of the Digital Image Processing course at Shiraz University.

The project focuses on spatial-domain image processing and includes manual implementations of several core algorithms.

## Main Topics

- Image Downsampling and Upsampling
- Nearest-Neighbor, Bilinear, and Bicubic Interpolation
- MSE and PSNR Evaluation
- Image Negative and Gamma Correction
- Piecewise-Linear Transformations
- Global and Local Histogram Equalization
- RGB-HSV Color Conversion
- Color Image Enhancement
- Histogram Specification / Matching

## Technologies

Python · NumPy · Matplotlib · Jupyter Notebook
